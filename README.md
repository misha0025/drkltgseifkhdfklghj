# Репрайсер для Wildberries

Локальная веб-панель с 18 демонстрационными товарами, расчётом цен, ручным и автоматическим подтверждением, имитатором WB и отчётом по периодам.

## Запуск

Нужен Python 3.10 или новее. В каталоге репозитория выполните:

```sh
python3 app.py
```

Откройте [127.0.0.1:8765](http://127.0.0.1:8765). Состояние сохраняется в `state.json`. Для чистого прогона задайте `REPRICER_STATE` с путём к новому файлу. Адрес и порт задаются переменными `REPRICER_HOST` и `REPRICER_PORT`. Для запуска на всех интерфейсах на порту 3000 выполните `REPRICER_HOST=0.0.0.0 REPRICER_PORT=3000 python3 app.py`.

Режим применения задаётся в «Правилах» отдельно для каждой категории. Автоматическое применение распространяется на новые рекомендации. После обновления старый режим по SKU сбрасывается в «Только рекомендации».

В «Товарах» ручные изменения и выбранные рекомендации собираются в пакет. «К отправке» открывает JSON задания, который отправляется в имитатор WB после подтверждения. Черновик хранится в текущей вкладке.

В «Интеграциях» можно запустить синхронизацию вручную, включить ежедневную синхронизацию и выбрать время по Москве. Она работает при запущенном сервере, в том числе без открытой панели. Если сервер запущен после указанного времени, он выполнит пропущенную синхронизацию за сегодня один раз. При ошибке можно запустить её вручную, следующая плановая попытка выполнится на следующий день.

Для демонстрации отдельного источника запустите во втором терминале `python3 demo.py`. В «Интеграциях» сохраните URL `http://127.0.0.1:8766/snapshot`, проверьте соединения и синхронизируйте данные.

```sh
python3 -m unittest discover -s tests -v
```
